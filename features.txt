# Features & Sprint Planning

## Feature 1: Adaptive Fitness Plan

### Description
Users answer a short onboarding questionnaire and receive a personalized weekly workout plan.

### Tasks

---

**Task 1.1 – Goal Setup Form UI**
**Assignee:** Susana
**Priority:** High
**Story Points:** 3
**Description:** Build the Goal Setup form with labeled input fields plus selectable buttons for Experience Level (Beginner / Intermediate / Advanced) and an Activity Level slider. 
- All three input fields display placeholder labels
- Experience level buttons are mutually exclusive (only one can be selected at a time)
- Activity level slider moves smoothly between low and high
- "Done" button is disabled until all fields are completed
- Form data is stored in state and passed to plan generation logic

---

**Task 1.2 – Weekly Schedule Screen**
**Assignee:** Nishan
**Priority:** High
**Story Points:** 3
**Description:** Display a 7-day weekly plan where each day row shows the day name, workout type, duration, and an icon.
- Each active workout day has a "›" chevron on the right
- Tapping an active day navigates to the correct Workout Detail screen
- Rest days do not navigate anywhere when tapped

---

**Task 1.3 – Workout Detail Screen**
**Assignee:** Tesfa
**Priority:** High
**Story Points:** 3
**Description:** Build the Workout Detail screen displaying the workout name, duration, a list of exercises with sets and reps, a "Start Workout" button, and a "Mark as Complete" button.
- Workout name and duration display at the top
- Exercise list shows at minimum 3 exercises with sets x reps format
- "Start Workout" button is prominent and triggers a timer or active state
- "Mark as Complete" button triggers navigation to the Completion screen

## Feature 2: Social Challenges

### Description
Users can browse active fitness challenges , view challenge details including participants and goals, join a challenge, invite friends, and track their daily progress on a dedicated progress screen with a leaderboard.

### Tasks

---

**Task 2.1 – Challenge Browse Screen**
**Assignee:** Tesfa
**Priority:** High
**Story Points:** 3
**Description:** Build the Community tab challenge browse screen showing a "Featured Challenge" card at the top and a list of "Other Challenges" below. Each card shows the challenge name, description, participant avatars, and a "›" chevron. Tapping a card navigates to the Challenge Detail screen.
**Acceptance Criteria:**
- Featured challenge is visually distinct from other challenges
- Each card shows name, short description, and participant count/avatars
- Tapping any card navigates to the correct Challenge Detail screen
- At minimum 3 challenges are displayed
- Layout is scrollable

---


**Task 2.3 – Progress Tracking Screen**
**Assignee:** Susana
**Priority:** High
**Story Points:** 3
**Description:** After joining a challenge, display the user's progress. Show a circular progress indicator with steps completed vs. goal, a weekly days tracker (M T W T F S S dots), and a prominent "CHECK LEADERBOARD" button placed above the days tracker. Remove redundancy with the pre-join screen.
**Acceptance Criteria:**
- Circular progress ring shows current steps / goal (e.g. 8,527 / 10,000)
- Days tracker dots correctly reflect completed days
- Leaderboard button is placed above the days tracker and is visually prominent
- Screen only appears after user has joined the challenge
- Daily progress updates reflect the current day's data

---

**Task 2.5 – Invite / Share Flow**
**Assignee:** Nishan
**Priority:** Low
**Story Points:** 2
**Description:** Implement the INVITE button flow that allows users to share a challenge link or invite friends from their contacts. 
- Share modal displays the challenge name and a shareable link
